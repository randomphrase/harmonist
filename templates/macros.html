{# Reusable Jinja rendering helpers. Import in a template with: {% from 'macros.html' import release_name %} #} {# An MB release name with its disambiguation rendered visually distinct — muted and parenthesised, the way MusicBrainz itself shows it. Pass the title and the (possibly empty) disambiguation separately. Wrap the call in an at the call site to make it a link; the muted styling still reads inside a coloured link. #} {% macro release_name(name, disambiguation) -%} {{ name }}{% if disambiguation %} ({{ disambiguation }}){% endif %} {%- endmacro %} {# The query string naming one Library view: which page, at what size, under which filter, matching which search. ONE definition because the Library page renders this string in twenty places — the container's refresh wiring, the page-size form, the search-widening link, every filter chip and both pager arrows (as an href AND an hx-push-url each), and the tile links — and a parameter dropped from any one of them is a control that silently throws away part of the view. That is not hypothetical: the set has grown from `page` to `page + limit` to `page + limit + filter` to this in four issues (#139, #144, #174, #180). Because Jinja renders a missing argument as an empty Undefined rather than raising, a call site left behind at three arguments would drop `q` on that one control and look completely fine. `make template-lint` therefore requires all four at every call site — a mechanical rule for a mechanical hazard. `filter` is omitted when falsy so All keeps the short URL — absence IS All, so there is no `filter=all` to spell. The slug is interpolated raw; that is safe because it reaches here only via `_library_filter`, which checks it against the known set. `q` is free text and gets no such guarantee, so it is urlencoded: a bare `&` or `#` in a query would end the URL early and silently drop whatever came after it. `page` is omitted when falsy too, which is how the filter and search controls ask for one: asking a new question starts at the first page of the answer, and the route's default is 1. Passing the current page across would request page 7 of a 3-album result. #} {% macro library_query(page, limit, filter, q) -%} {% if page %}page={{ page }}&{% endif %}limit={{ limit }}{% if filter %}&filter={{ filter }}{% endif %}{% if q %}&q={{ q | urlencode }}{% endif %} {%- endmacro %}
