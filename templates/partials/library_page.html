{# One page of the Library grid — header, tiles, pager — rendered as a whole. It used to be an accumulator: the first page opened #library-grid and every later page appended tiles plus a fresh Load-more button. That made the grid's position unaddressable (it only existed as DOM you'd built by clicking), so a trip to an album page and back dumped you on the newest 30 (#139). Each page is now a complete, self-describing render that replaces #library-rows. The root element below carries the refresh wiring, so each render re-requests the page it is actually showing. Putting that on the #library-rows container instead needs the page in an `hx-vals`, and hx-vals is INHERITED: every pager link inside would then send its own `?page=2` plus the container's `?page=1`, and the last value wins — which silently pinned the grid to page 1. Here there is no inherited value to collide with, and a refresh mid-browse (every `tasks-changed`) keeps you on your page. #}
