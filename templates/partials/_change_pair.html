{# How History draws one recorded change, before and after. Shared by a tagging's field rows and an artist NFO write's (#981), so a change reads the same wherever Harmonist recorded one. A row `c` needs `is_id`, and for an id row `parts(value)`: the ids in a value and the separators between them. #} {# A MusicBrainz id row's value (#801): each id as its name, linked to its page with the full id as the tooltip, or cut short where the album's stored release doesn't name it, and the separators between them as written. #} {% macro id_value(c, value) -%} {%- for p in c.parts(value) -%} {%- if p is string -%}{{ p }}{%- else -%}{{ p.label }}{%- endif -%} {%- endfor -%} {%- endmacro %} {# One value as written: named ids for an id row, otherwise the value with what changed in it marked (`runs`, empty when there is nothing useful to mark). #} {% macro value_of(c, value, runs) -%} {%- if c.is_id %}{{ id_value(c, value) }}{% else %}{% with value = value %}{% include 'partials/_diff_runs.html' %}{% endwith %}{% endif -%} {%- endmacro %} {# A before-and-after pair. A field with nothing before it shows only what was written. On a first tagging that is EVERY row, so "— →" would prefix the whole list with two columns of chrome, and the em-dash reads as a value rather than as the absence of one. The arrow stays where it carries the meaning: a replacement has two real sides, and a removal has to say what went. `removed_by` names what removed a value, for the removal's tooltip. #} {% macro pair(c, before, after, before_runs, after_runs, removed_by='this tagging') -%} {%- if before is not none -%} {{ value_of(c, before, before_runs) }} → {%- endif -%} {%- if after is none -%} removed {%- else -%} {{ value_of(c, after, after_runs) }} {%- endif -%} {%- endmacro %}
