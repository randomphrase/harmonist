{# The album's tracks against its MusicBrainz release, field by field (#135). The table's columns are `tracklist.columns` and each row's cells are `ComparedTrack.fields` in the same order — so both come from the model, rather than the headings being written out here and hoped to line up. Which columns those are is EARNED, per album (#309). A per-track tag gets one when it answers *which track*: it differs from MusicBrainz and not identically on every track, the tracks disagree with each other, or it differs from the album-level value. That is what puts a per-track change — an artist sort on track 6, an ISRC MusicBrainz filled in differently per recording — beside the track it belongs to, where the re-tag box below could only ever state it as "1 of 7 tracks" and leave the reader to work out which. Otherwise the column is N rows saying one thing, and it is not drawn. Where that one thing is agreement, the tag is named under the table with its value a disclosure away; where it is a change every track shares, the box states it once, which is the whole of it. The medium-derived three — disc subtitle, media, track total — are a fourth case, and they go to the DISC HEADING (#320). They vary per track only in the sense that they vary per disc, which the heading above each group already states, so a column of them repeats one value down a whole disc. See `DiscHeading`. Two lines per track, not two columns: a track that agrees is one plain line, and a track that differs gains a second beneath it in mb-purple carrying only the cells that actually differ. Both values keep the same left edge and the same column, so a difference is a vertical scan rather than a comparison. Same register as the album panel above — most of these are formatting differences, not errors, and nothing is coloured as a mistake. A video track is a third shape (#226): present, marked, and carrying only its own values — Harmonist reads `.m4v` tags but never writes them, so comparing one against MusicBrainz would raise differences no re-tag could ever settle.
