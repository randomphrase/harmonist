A row that would be written to says so in a line of its own. There is no second column: its only possible occupant was the folder cover, which by then already has a row here — it gets one whenever no track carries it, which is exactly when something is replaced or filled — so the column could never show anything the reader could not already see (#406). An album assembled over decades having uneven artwork is normal and a compilation having four covers is correct, so nothing here is coloured as a fault. What a re-tag would write takes the Tags panel's purple, because it is the same kind of value: what Harmonist would put over what you have.
